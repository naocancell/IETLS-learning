# IELTS Master - 剑桥雅思全真机考与精听精读系统

一个高度还原英国文化教育协会官方雅思机考（CD-IELTS）体验、同时深度支持日常精听精读与刷题诊断的本地原生桌面客户端应用。

## 🌟 核心特色

### 1. 🎯 全真模考模式 (Official Mock Exam)
- **官方考场级还原**：1:1 遵循官方机考的界面布局、配色体系与规范排版。
- **倒计时与强制交卷**：全真限时倒计时（听力 30 分钟，阅读 60 分钟），支持倒计时预警。
- **阅读交互与高亮**：
  - 支持鼠标自由拖拽调整左右分栏宽度。
  - 划选文章任意文字，即刻弹出 **Highlight（高亮）** 标记工具，支持一键高亮与清除标记。
- **全景 40 题导航网格**：已答（实心蓝）、未答（镂空）、复查标记（Review 黄色圆点），点击直接定位。
- **官方 9 分制智能换算**：交卷后自动生成《雅思成绩诊断报告》，将原始正确数（Raw Score 0~40）智能换算为 **雅思等级分（Band Score 0~9.0）**。

### 2. 📖 日常刷题与精听精读模式 (Study & Practice)
- **专业精听播放器**：支持进度条无级拖拽、**快退 5 秒（↺ -5s）**、**快进 10 秒（↻ +10s）**，以及 **0.75x ~ 1.5x 多档倍速调节**。
- **中英双语录音原文 (Tapescript) 对照**：一键展开录音文本，出题点带有专属的 **`【考点定位 Q1】`** 彩色徽章，点击徽章直达对应题目。
- **单题即时核对 (Check Answer)**：做完一题立即判断正误，并展示**官方标准答案与同义替换考点解析**。
- **错题复盘**：成绩单支持一键筛选“仅看错题”，便于重做与查漏补缺。

## 🚀 启动与使用方式

在 Windows 系统下：
- **方式一（推荐，无黑框独立应用）**：双击根目录下的 **`启动客户端(无黑框版).vbs`**。
- **方式二（标准命令行启动）**：双击根目录下的 **`启动雅思答题客户端.bat`** 或 **`run.bat`**。

## 📂 项目结构

```text
├── 启动客户端(无黑框版).vbs       # [推荐] 双击秒开原生独立客户端 (无命令行窗口)
├── 启动雅思答题客户端.bat         # 命令行启动脚本
├── run.bat                        # 英文启动脚本
├── 题目/                          # 剑桥雅思 PDF 真题资料
├── 听力/                          # 雅思听力音频压缩包 (含剑4全真音频)
└── ielts_client/                  # 客户端核心实现
    ├── app.py                     # 客户端主入口 (Edge WebView2 原生桌面视窗)
    ├── build_cambridge4.py        # 题库结构化与音频切片生成器
    ├── data/                      # 结构化题库 (JSON 格式)
    │   ├── cambridge4_listening.json
    │   └── cambridge4_reading.json
    └── web/                       # 离线前端引擎
        ├── index.html             # 主界面
        ├── css/style.css          # 离线样式库
        ├── js/app.js              # 交互引擎、评分算法、音频驱动
        ├── js/exam_data.js        # 静态题目数据
        └── audio/                 # 听力音频切片
```

## 三、题库数据格式（schema v2）

一套题 = `ielts_client/data/cXX/tY/` 目录（如 `c05/t1`），里面 `listening.json` 和/或 `reading.json`。完整示例直接看 `data/c04/t1/`。

### 顶层

```jsonc
{
  "schema_version": 2,
  "book": 5, "test": 1,
  "module": "listening",            // 或 "reading"
  "variant": "academic",            // 仅阅读：academic / general
  "title": "Cambridge IELTS 5 · Test 1 · Listening",
  "verified": false,                // 与官方答案逐题核对后再改成 true
  "source": { "pdf": "题目/Cambridge-IELTS-05.pdf", "pages": [10, 17], "note": "答案来源说明" },
  "parts": [ ... ]
}
```

### Part

- 听力：`number`、`title`、`audio`（如 `"c05/t1/s1.mp3"`）、`transcript`（如 `"transcript_s1.json"`）、`questions_range`、`groups`。
  一整套只有一个音频文件时，各 Part 用同一个 `audio`，并写 `audio_start` / `audio_end`（秒）。
- 阅读：`number`、`title`、`passage_title`、`intro`（“You should spend about 20 minutes…”）、`passage`、`questions_range`、`groups`。

### 题组 group（公共字段）

| 字段 | 说明 |
|---|---|
| `range` | `[起, 止]` 题号 |
| `type` | `completion` 填空 / `single_choice` 单选 / `multi_choice` 多选 / `tfng` / `ynng` / `matching` 配对（下拉选择） |
| `category` | 统计用题型，如 `note_completion`、`table_completion`、`sentence_completion`、`summary_completion`、`short_answer`、`plan_labelling`、`map_labelling`、`diagram_labelling`、`multiple_choice`、`matching`、`matching_headings`、`matching_information`、`matching_features`、`tfng`、`ynng` |
| `instruction` | 题目要求，原样照抄（`**粗体**` 表示原书大写加粗部分），`\n` 换行 |
| `limit` | 填空题字数限制：`{"words": 2, "number": true}` 表示 “NO MORE THAN TWO WORDS AND/OR A NUMBER”；“ONE WORD ONLY” 写 `{"words": 1, "number": false}` |
| `template` | 笔记/表格/流程图/摘要的版面，空位写 `{{题号}}`（一题两空写 `{{11.1}}`、`{{11.2}}`） |
| `title` / `image` / `example` | 题组标题 / 图片（相对本套题目录，如 `img/l_s2_plan.png`）/ 示例 |
| `options` / `options_title` | 配对题、多选题的选项 `[{"key":"A","text":"..."}]` |
| `select_inline` | `true`：带词库的摘要题，在 `template` 的空位处直接显示下拉框 |

### 题目 question

| 字段 | 说明 |
|---|---|
| `id` | 题号 |
| `prompt` | 题干；句子填空/简答题把空位写在题干里：`"... fuels such as {{11.1}} and {{11.2}}."` |
| `answer` | **数组**，每个元素是一个可接受答案。`"(the) American Museum"` 括号内可省略；`"dolphin(s)"` 单复数皆可；判断题写全称 `["NOT GIVEN"]`；选择题写字母 `["B"]` |
| `blanks` + `any_order` | 一题多空：`"blanks": 2, "answer": [["coal"], ["firewood"]], "any_order": true` |
| `options` | 单选题选项 |
| `evidence` | 阅读：原文中的依据句（**必须与 passage 中的文字完全一致**，“定位原文”靠它高亮） |
| `t` | 听力：答案在录音中出现的秒数（`tools/transcribe.py --locate` 可自动填） |

多选题（Choose **TWO** letters）：一组只写一次 `options` 和 `answer_set`，小题只写 `id`：

```json
{ "range": [21, 22], "type": "multi_choice", "category": "multi_choice",
  "instruction": "Choose **TWO** letters, **A–E**.",
  "prompt": "Which TWO problems does the speaker mention?",
  "options": [{"key":"A","text":"..."}, {"key":"B","text":"..."}, {"key":"C","text":"..."}, {"key":"D","text":"..."}, {"key":"E","text":"..."}],
  "answer_set": ["B", "D"],
  "questions": [{"id": 21}, {"id": 22}] }
```

### 版面标记（template / passage / prompt 通用）

- `# 标题`、`## 小标题`；`- 列表`（两个空格缩进为下一级）
- 表格：`| a | b |`，第二行写 `|---|---|` 表示第一行是表头；格内换行用 `<br>`
- `> 引用`（示例、脚注）；`![说明](img/xxx.png)` 图片；`**粗体**`、`*斜体*`
- 阅读段落用空行分隔；带字母的段落以 `[A] ` 开头

### 听力原文 transcript_sN.json

```json
{ "source": "asr", "model": "faster-whisper small.en",
  "segments": [ { "start": 0.78, "end": 31.49, "text": "..." } ] }
```

如果书里有 Tapescript，可以把 `source` 改为 `"book"`，把文字按句替换进 `text`（保留时间），界面就不再显示“语音识别”提示。

## 四、剑5–21 导入步骤

> 以剑5 Test 1 为例。先装工具依赖：`.venv\Scripts\pip install -r requirements-tools.txt`（另外建议安装 ffmpeg 并加入 PATH）。

1. **放资料**：PDF 放 `题目/`，音频 zip 或文件夹放 `听力/`（文件名保持原样即可）。
2. **检查音频识别**：`python tools/prepare_media.py --check -v`
   每套应识别到 `s1–s4` 四段；识别不了或识别错的，在 `听力/audio_map.json` 里手动指定（见下文）。
3. **提取 PDF**：`python tools/pdf_extract.py 题目/Cambridge-IELTS-05.pdf`
   得到 `work/c05/pages/p###.txt` 和页面索引 `work/c05/index.txt`；提示“没有 Answer key / Tapescript”时要另找来源。
4. **建模板**：`python tools/new_test.py 5 1`（培训类阅读加 `--general`），生成 `data/c05/t1/` 下的空白 JSON。
5. **录入题目**：对照原书页面（`--render 页码` 出图）逐组填写 `groups`，原文、题干、选项**原样照抄**，不要改写。
6. **截图**：地图/平面图/流程图/图表：`python tools/pdf_extract.py 题目/xxx.pdf --crop 页码 x0,y0,x1,y1 ielts_client/data/c05/t1/img/l_s2_map.png`（坐标单位 pt，可先 `--render` 看图估算）。
7. **填答案**：按官方 Answer key 填 `answer`，`/` 拆成多个元素，`( )` 原样保留；阅读每题尽量补 `evidence`。
8. **听力原文与时间点**：`python tools/transcribe.py c05/t1`（CPU 上 small.en 约 2–3 分钟/段；想更准用 `--model medium.en`）。选择/配对题无法自动定位，按原文手动补 `t`。
9. **校验**：`python tools/validate_data.py c05/t1`，直到 0 错误。
10. **实际做一遍**：启动程序，练习模式下每组“核对本组答案”，确认版面、答案、▶ 听原文 都正常后，把 `verified` 改成 `true`。
11. **提交**：只提交 `ielts_client/data/c05/`（JSON、transcript、img），PDF 和音频不提交。

## 五、导入注意事项（重点）

### 1. 先确认资料本身可信

- **剑4 的 PDF 不含答案和录音原文**，而且是手打重排版（有错字、漏句）。剑5–21 的 PDF 请逐本确认：
  - 书末是否有 **Listening and Reading Answer Keys** 和 **Tapescripts / Audioscripts**（`pdf_extract.py` 会提示）；
  - 是原书扫描/原版电子版，还是重新排版的版本（重排版常见：错字、漏句、题号错位、图表缺失）；
  - 扫描版没有文字层，需要 OCR 或手动录入。
- 答案以**原书 Answer Key** 为准；网上答案只能作为交叉核对，发现分歧时回到原文/录音判断。
- **不要用 AI 改写或“补全”题目和原文**——这次剑4 旧数据的大部分问题都来自这里。

### 2. 每本书的结构差异

- 剑4–剑10 等早期书：4 套 Academic 测试 +（部分书）书末 General Training 阅读/写作 Test A、B；后期学术类、培训类分成两本书。以手上的书为准，培训类阅读请设 `"variant": "general"`（分数换算表不同）。
- 听力早期叫 **Section 1–4**，新书叫 **Part 1–4**；数据里统一用 `number`，`title` 照书写。
- 新书的填空要求多为 **ONE WORD ONLY / ONE WORD AND/OR A NUMBER**，老书多为 **NO MORE THAN THREE WORDS AND/OR A NUMBER**，`limit` 一定要按每组的要求写。
- 新书阅读常见 “Choose **TWO** letters” 多选、“NB You may use any letter more than once”（照抄进 instruction）、配对题选项比题目多。

### 3. 答案写法

- 答案页的 `/` = 多个可接受答案；`( )` = 可省略部分；**但带上可省略部分后不能超过字数限制**。
  例：剑4 Q6 限 3 词，答案页是 `Tower of London`，就不要写成 `(the) Tower of London`（`the Tower of London` 是 4 个词，考试中算超字数）。校验工具会检查这一点。
- “IN EITHER ORDER” 分两种：
  - 两个题号各 1 分（如 Q21–22 选两项）→ `multi_choice` + `answer_set`；
  - 一个题号两个空、两空都对才得分（如剑4 Q11 coal + firewood）→ `blanks: 2` + `any_order: true`。
- 数字统一写阿拉伯数字（`160`），日期按答案页写（`13th February`；判分会自动接受 `13 February` / `February 13th` 等写法）。
- 英美拼写（colour/color、centre/center）如答案页两种都给，就都写进 `answer`。
- 判断题只能写 `TRUE` / `FALSE` / `NOT GIVEN` 或 `YES` / `NO` / `NOT GIVEN`（全大写全称）。

### 4. 听力音频

- 自动识别规则（文件名或所在目录/压缩包名）：
  - 书号：`IELTS04`、`Cambridge IELTS 5`、`剑桥雅思5`、`剑5`、`C5T1S1`…
  - 套号：`Test 1`、`T1`、`第1套`
  - 段号：`Section 1`、`Part 1`、`S1`、`P1`、`第1部分`
- 老书 CD 常见 `CD1/Track 02.mp3` 这种命名，无法自动识别，用 `听力/audio_map.json` 指定：

  ```json
  {
    "c05/t1/s1.mp3": "Cambridge 5/CD1/Track 02.mp3",
    "c05/t1/s2.mp3": "Cambridge-IELTS-05.zip::CD1/Track 03.mp3"
  }
  ```

  左边是题库里的 `part.audio`，右边是相对 `听力/` 的路径，zip 内文件用 `压缩包::包内路径`。
- 一套题只有一个音频文件：各 Part 写同一个 `audio`，用 `audio_start` / `audio_end` 切分。
- 有的音频开头带 “Test 1 … You will hear …” 的说明或段与段之间的停顿，属于正常内容；模考时整段播放。
- 建议用 mp3；其他格式请让 `part.audio` 的扩展名与实际文件一致。
- 音频放在别的盘：复制 `config.example.json` 为 `config.json`，`"audio_dirs": ["听力", "D:/IELTS/听力"]`。

### 5. 听力原文

- 书里有 Tapescript：优先用书上的文字（`source: "book"`），更准确，且能标出答案句。
- 没有 Tapescript：用 `tools/transcribe.py` 生成，界面会提示“语音识别，仅供参考”。识别模型可能把人名/拼写类答案听错（例如拼读的 `Y-E-N-T-O-B`），**不能用识别结果当答案来源**。
- `--locate` 只能定位填空题；选择、配对、地图题请对照原文手动补 `t`（秒），定位不准时 ▶ 听原文 会跳偏。

### 6. 阅读原文与图片

- 原文按书分段，保留段落字母（`[A]`）、标题、副标题、脚注（用 `>`）。
- PDF 复制出的文字要处理：行尾连字符断词、`ﬁ/ﬂ` 连字、全角引号、页眉页脚和页码。
- `evidence` 必须是原文里**一字不差**的一段（校验工具会检查），用于“定位原文”。
- 地图、平面图、流程图、图表题要截图放 `img/`，图上题号要清楚；文章里的插图用 `![Fig. 1](img/xxx.png)`。

### 7. 核对与标记

- `verified: false` 的题库界面会显示“未核对”。只有在 **题目原样 + 答案与原书一致 + 实际做过一遍** 后才改为 `true`。
- 每套题导入后都跑 `python tools/validate_data.py`，提交前跑一次全量校验和 `node tools/test_scoring.js`。

### 8. 版权与仓库体积

- 剑桥原书与音频受版权保护。建议仓库设为 **Private**；不要把剑5–21 的 PDF/音频提交到公开仓库。
- 题库 JSON + 截图每套约 100–300KB，18 本 × 4 套也只有十几 MB，可以放心提交。
